## 🚀 How to Present

### Option A: Open with Microsoft PowerPoint / Google Slides
Simply open:
```
AgriOne_Silent_Coders_Presentation.pptx
```
Press **F5** to start slideshow mode.

### Option B: Interactive Web Presentation (Recommended for Wow Factor)
Double-click `index.html` to open in Google Chrome, Edge, or Brave, or serve locally:
```bash
python -m http.server 8085
```
Open [http://localhost:8085](http://localhost:8085) in your browser.

#### Presentation Keyboard Shortcuts:
| Key | Action |
|---|---|
| `→` / `Space` / `PgDn` | Next Slide |
| `←` / `PgUp` | Previous Slide |
| `F` | Toggle Fullscreen Mode |
| `O` | Toggle 36-Slide Overview Grid |
| `N` or `P` | Toggle Speaker Notes Modal |
| `Home` | Jump to Slide 1 (Team Intro) |
| `End` | Jump to Slide 36 (Thank You) |
| `Esc` | Close any active modal |
